# Engine V3 — Archived Legacy 2D Character Studio

This directory is retained only for backward compatibility with old 2D character projects. It is not part of the current Skil-cc film pipeline.

## Current production
Use `../engine-v4/` for 3D previs and the parent `../SKILL.md` for the full 5–10 minute film workflow. New film assets must be volumetric 3D.

## Legacy source
The original Canvas 2D character editor, rig controls, presets and short timeline remain here so older project files can still be inspected. Do not use this engine to create new shots for a full-3D film.
