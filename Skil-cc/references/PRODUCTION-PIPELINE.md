# Production Pipeline

## 1. Source lock
Read the full active screenplay and support files. Record file paths, source versions and unresolved conflicts. Do not begin production from a summary if the source document exists.

## 2. Story lock
Create logline, synopsis, character objectives, opposition, stakes, causal beat sheet, climax and resolution. Verify that every important event has a cause and consequence.

## 3. Runtime lock
Target 300–600 seconds. Allocate scene durations, then shot durations. Keep dialogue performance realistic. Include transitions and audio tails in final runtime.

## 4. Pre-production
Create character bible, location bible, props, asset IDs, materials, rig plan, shot list, storyboard and animatic.

## 5. Production
Model and texture in 3D, rig characters, animate in passes, build sets, light scenes, create effects and record/align audio. Use Blender for full production. Use engine-v4 for previs only.

## 6. Post-production
Edit scenes, sync dialogue, mix sound, colour manage, render image sequences, assemble final video and inspect every shot.

## 7. Delivery
Include editable source project, asset manifest, final video, final screenplay/shot list, audio files, render settings and QA report. State missing assets and unfinished tasks.
